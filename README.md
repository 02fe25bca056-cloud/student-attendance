# Student Attendance and Performance Management System

## 1. Project Overview
This project is a web-based application developed using Python and Flask to manage student attendance digitally.

## 2. Technologies Used
- Python
- Flask
- SQLite
- HTML
- Docker
- Docker Hub
- Kubernetes
- Jenkins
- GitHub

## 3. Features
- Digital attendance management
- Web-based application
- Database integration
- Docker containerization
- Kubernetes deployment
- Jenkins build process

## 4. Project Files
- `app.py` - Main application file.
- `templates/` - Contains HTML templates.
- `requirements.txt` - Required Python libraries.
- `Dockerfile` - Instructions to build a Docker image.
- `deployment.yaml` - Kubernetes deployment configuration.
- `.gitignore` - Specifies files Git should ignore.
- `README.md` - Project documentation.

## 5. How to Run
Install dependencies:

`pip install -r requirements.txt`

Run the application:

`python app.py`

Open in a browser:

`http://localhost:5000`

## 6. Docker Commands
Build the image:

`docker build -t student-attendance .`

Run the container:

`docker run -p 5000:5000 student-attendance`

## 7. Project Objective
The objective is to learn web application development and DevOps tools, including GitHub, Docker, Kubernetes, and Jenkins.
